# رائد التاريخ 🏛️
### تطبيق تعليمي احترافي لمادة التاريخ — للطالب والمعلم

تطبيق يعمل **بدون إنترنت بالكامل**، مبني بتقنية **Flutter** (أندرويد + آيفون)، مأخوذ محتواه من كتاب التاريخ الرسمي الصادر عن وزارة التربية والتعليم اليمنية للصف التاسع الأساسي (الفصلين الأول والثاني).

> إعداد/فكرة: عبدالكريم الزوعري

---

## 🎯 الفكرة العامة
تطبيق يساعد الطالب على الفهم والمراجعة والاختبار الذاتي، ويساعد المعلم على شرح الدروس بطريقة مبسطة وجاهزة، مع دعم ذكاء اصطناعي (أوفلاين حسب الإمكان، وأونلاين عند توفر الاتصال).

## 👥 المستخدمون
عند أول تشغيل: إنشاء حساب (اسم + كلمة مرور) ثم اختيار الدور:
- **معلم** → واجهة شرح الدروس (ترم أول / ترم ثاني → دروس → شرح مفصّل مع صور توضيحية)
- **طالب** → واجهة تفاعلية كاملة (ترم أول / ترم ثاني / الكتاب المدرسي كـ PDF)

## 🧩 ميزات واجهة الطالب (لكل ترم)
| الميزة | الوصف |
|---|---|
| 📝 نماذج اختبارات لكل درس | ١٥٠–٢٥٠+ سؤال (صح/خطأ ثم اختيار من متعدد) لكل درس، بلا تنقل قبل الإجابة، تصحيح فوري + تقرير أداء (نسبة من ١٠٠، وقت الحل، أسئلة صح/خطأ قابلة للمراجعة مع الرجوع لمكان الإجابة في الشرح/الملخص/الكتاب) |
| 📄 ملخصات الدروس | ملخص مبسّط لكل درس |
| 🎙️ الشرح | شرح كامل لكل درس + زر قراءة صوتية للدرس كاملاً + قراءة صوتية للنص المحدد |
| 🗂️ اختبارات الوحدات | اختبار شامل للوحدة أو للترم كاملاً |
| 🔁 الأوتوماتيك | تسلسل تلقائي: شرح ← ملخص ← اختبار ← تقييم (بالدرس أو بالوحدة)، مع زر إيقاف مؤقت |
| 🕘 سجل التحليل | سجل بالتاريخ والوقت لكل نشاط اختبار/مراجعة (في القائمة الجانبية) |
| 🌙 الوضع الليلي | تبديل بين فاتح/داكن |

## 🎨 الهوية البصرية
تصميم عصري بلمسة يمنية (زخارف، شعار الجمهورية اليمنية، أصوات تاريخية يمنية اختيارية)، خط عربي واضح جدًا، صور شرح لكل درس.

## 🤖 الذكاء الاصطناعي (أوفلاين + أونلاين)
- **بدون إنترنت:** نموذج مضغوط محلي (TensorFlow Lite / ONNX) للإجابة على أسئلة مباشرة أو توضيح مصطلح من محتوى الكتاب المخزّن محليًا فقط (بدون توليد حر) — راجع `docs/AI_STRATEGY.md`.
- **مع إنترنت:** ربط اختياري بواجهة API (مثل Claude) لإجابات أوسع وتوليد أسئلة إضافية.

## 🏗️ التقنية
- **Flutter** (Dart) — تطبيق واحد لأندرويد وآيفون
- **Hive / SQLite** — تخزين محلي للمستخدمين، النتائج، سجل التحليل
- **flutter_tts** — القراءة الصوتية
- **flutter_pdfview** — عرض الكتاب المدرسي كـ PDF داخل التطبيق
- محتوى الدروس والأسئلة كملفات **JSON** محلية (`assets/data/`) ليعمل التطبيق كاملاً بدون إنترنت

## ✅ الحالة الحالية (جاهز للتشغيل التجريبي)
- محتوى كامل لـ 18 درسًا (الفصلين الدراسيين كاملين) بصياغة تعليمية مبسّطة: ملخص + شرح موسّع لكل درس.
- بنك أسئلة يضم أسئلة صح/خطأ واختيار من متعدد لكل درس (قابل للتوسعة إلى مئات الأسئلة بنفس البنية في `assets/data/questions.json`).
- تدفق كامل شغّال: تسجيل دخول ← اختيار الدور ← قائمة الترمين ← الخيارات الخمسة (اختبارات/ملخصات/شرح/اختبارات وحدات/أوتوماتيك) ← تنفيذ فعلي لكل خيار.
- محرك اختبار حقيقي: صح/خطأ ثم اختيار من متعدد، سؤال واحد بالشاشة، إيقاف مؤقت، تقييم شامل مع مراجعة الأخطاء وربطها برقم صفحة الكتاب.
- قراءة صوتية (TTS) للشرح والملخص.
- واجهة معلم منفصلة للوصول السريع للشرح.

## 🚀 خطة البناء المتبقية
راجع [`docs/ROADMAP.md`](docs/ROADMAP.md) للمراحل التفصيلية المتبقية (الصور التوضيحية، عرض الكتاب كـ PDF فعليًا، سجل التحليل المتصل بقاعدة البيانات، التصميم اليمني الكامل)، و[`docs/AI_STRATEGY.md`](docs/AI_STRATEGY.md) لاستراتيجية الذكاء الاصطناعي أوفلاين/أونلاين.

## ⚠️ خطوة أخيرة لا بد منها: تشغيل المشروع فعليًا على هاتفك
لا يمكن لأي أداة توليد "تطبيق جاهز للتثبيت مباشرة" بدون بيئة بناء (Flutter SDK + Android Studio/Xcode)، لأن هذا المشروع كود مصدري احترافي كامل وليس تطبيقًا مُصرَّفًا. الخطوات لتشغيله (نسخ ولصق فقط، بلا كتابة كود):
1. ثبّت Flutter من الموقع الرسمي: https://docs.flutter.dev/get-started/install
2. افتح مجلد المشروع في VS Code أو Android Studio.
3. نفّذ الأمرين التاليين في الطرفية داخل مجلد المشروع:
   ```bash
   flutter pub get
   flutter run
   ```
4. لبناء ملف APK لتثبيته مباشرة على أي هاتف أندرويد:
   ```bash
   flutter build apk --release
   ```
   الملف الناتج يكون في: `build/app/outputs/flutter-apk/app-release.apk`
